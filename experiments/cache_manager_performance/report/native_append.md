# Production append allocation evidence

The promoted `sparse_append_free` path was checked separately against three actual GPU before-states with 0, 8,192 and 65,536 resident records; P=65,664, start=65,536, append=128, width=576 BF16, clock=17. All 128 selected slots were distinct legal free slots with priority -1 and no owner. CPU reconstruction verified every semantic record, reciprocal mapping, free bit, priority and clock byte against the saved actual state. History and sentinel bytes stayed unchanged, the clock advanced to 18, and evictions remained zero. Scratch outputs are bound to saved bytes rather than independently recomputed.

The diagnostic used the same actual production ECHO ELF as the original manager06 and recall04 runs: `d888ee0cb2aa864ed1dcde9dee5e814a2468ce57c643b19dc138141106f2568e`. Its independent acceptance remains in `/tmp/cache_append_production_state_20261006_01/`; [the audit](native_append_audit.json) binds saved state, source and receipt hashes. This is correctness evidence, not a standalone performance experiment.

The manager check/bench/profile independently validate subsequent workload selections and traffic; they are not continuations of these three native fixtures. Cold ECHO and serial sparse each transfer 22,799,232 H2D bytes across three layers; dense prefetch transfers 226,492,416 H2D bytes. Prefill and warm H2D are zero. Offload D2H is 1,179,648 bytes per layer for the final prefill chunk and 147,456 bytes per layer for extend. No evictions, capacity splits or prefetch capacity failures occurred.

The 24 prepare-mask/select-slot activities are GPU control. Their exposed duration remains gap under `window - union(compute, actual IO)`. D2D and empty gather also remain gap; counter-proven zero-IO fused indexer remains compute. These cache-only results do not establish full-model or per-layer gap gates, MFU, physical memory budgets or continuous GPU isolation.

This retained native append01 acceptance keeps its original identity and receipt. Manager07 uses ECHO ELF `09165f76c0ef4a75067939afa1c071bb68b9e8bf28e229d27681cbefdb2e0a11`, which is a different ELF. The [scope check](retained_scope.json) verifies unchanged append/recall source and other ECHO AST nodes, while the [payload comparison](native_payload_comparison.json) establishes equal CUDA payload bytes only. Neither establishes host-wrapper binary equivalence or the new resident-mask Triton CUBIN identity.
