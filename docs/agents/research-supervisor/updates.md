# 重要研究理解与修正

这里只记影响研究解释或任务选择的变化。文档维护和具体工具输出不逐条记录。

## 2026-10-02：缩小 Supervisor 的产物职责

- **来自研究者：**项目探索历程不应成为论文或组会的任务定义；Supervisor 生成的研究叙事质量不足。
- **修正：**删除研究叙事产物，取消 Supervisor 的叙事生成职责，后续由其他 agent 组织呈现。
  Supervisor 维护研究状态和简短下一步；roadmap 移除已完成任务和长篇任务说明。
- **影响：**这是维护方式与职责的调整，不改变已有研究判断的成熟度。下列旧记录中涉及叙事产物的安排已撤销。


## 2026-10-01：按研究者修正建立第一版

- **来自研究者：**presentation 始终围绕实验室四环节，内部运行核验与给人的研究叙事分层。
- **修正：**研究状态以问题、baseline、challenge/design、evaluation 为中心；
  不再把数值/运行验证清单作为研究呈现结构。
- **影响：**全部条目；状态表、叙事、任务和内部材料分开维护。

- **来自研究者：**当前从 sparse KV fetching 与 sparse attention overlap 的 design 出发寻找场景；
  sparse attention GR serving 尚不确定，需要逐步补全模型、数据及负载。
- **修正：**允许第一环未知时继续第三环的探索；不要求按最早未完成环节逐一通过。
  人的修正会改变后续工作；agent 提出的场景路线不自动成为已采纳的选择。
- **影响：**1.1–1.5、3.1–3.3；T-002 与 T-005 可按各自已知部分推进。

- **来自研究者：**当前先关注 CPU DRAM，CXL/RDMA 不一定重要。
- **修正：**本轮范围设为 HBM 与 CPU DRAM，未为 CXL/RDMA 建立任务或验证前提。
- **影响：**2.2–2.5、4.1；后续范围变化仍由研究者输入更新。
